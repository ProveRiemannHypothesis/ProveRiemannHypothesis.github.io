# Riemann Hypothesis Lean verification archive

[Verification dashboard](https://proveriemannhypothesis.github.io/) · [Downloads and checksums](https://proveriemannhypothesis.github.io/downloads.html) · [Original text logs](https://github.com/ProveRiemannHypothesis/ProveRiemannHypothesis.github.io/releases/tag/verification-2026-11-21)

The website is a static archive of the completed run. Its final build, axiom audit, skipped kernel replay, hardware sample and storage reading are available without the original server. The page renders the complete record without JavaScript. A small script formats event times in the visitor’s timezone.

The download index lists all 31 public files from the former verification host, including SHA-256 evidence for the original bytes. The two large logs are hosted unchanged in the release, with gzip copies on Pages. The original source archive checksums are in `artifacts/SHA256SUMS`. The frozen status and storage JSON are also served at `/api/status` and `/api/storage`.

Historical server address: `106.14.11.164`. [Wayback Machine capture of the original home page, 21 November 2026 at 05:22:33 UTC](https://web.archive.org/web/20261121052233/http://106.14.11.164/).
